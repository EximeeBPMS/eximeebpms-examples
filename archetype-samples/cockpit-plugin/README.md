# EximeeBPMS Cockpit Plugin
A simple plugin that showcases the plugin system of Cockpit, the process monitoring tool of [EximeeBPMS](https://docs.eximeebpms.org).

This project has been generated by the Maven archetype
[eximeebpms-archetype-cockpit-plugin-1.3.0](https://docs.eximeebpms.org/manual/latest/user-guide/process-applications/maven-archetypes/).

## How to use it?
Build the plugin with `mvn clean install`.

Afterwards, you can install the plugin as described in [our guide](../../examples/cockpit/cockpit-fullstack-count-processes#integrate-into-eximeebpms-webapp).

Once you installed the plugin it should appear in
[EximeeBPMS Cockpit](https://docs.eximeebpms.org/manual/latest/webapps/cockpit/).
