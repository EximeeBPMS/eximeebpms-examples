## How to use it?

### Unit Test
You can run the JUnit test [ProcessUnitTest](src/test/java/org/example/eximeebpms/bpm/ProcessUnitTest.java) in your IDE or using:

```bash
mvn clean test
```

### Running the application
You can also build and run the process application with Spring Boot.

#### Manually
1. Build the application using:

```bash
mvn clean package
```
2. Run the *.jar file from the `target` directory using:

```bash
java -jar target/eximeebpms-process-application.jar
```

For a faster 1-click (re-)deployment see the alternatives below.

#### Maven Spring Boot Plugin
1. Build and deploy the process application using:

```bash
mvn clean package spring-boot:run
```

#### Your Java IDE
1. Run the project as a Java application in your IDE using EximeeBpmsApplication as the main class.

### Run and Inspect with Tasklist and Cockpit
Once you deployed the application you can run it using
[EximeeBPMS Tasklist](https://docs.eximeebpms.org/manual/latest/webapps/tasklist/)
and inspect it using
[EximeeBPMS Cockpit](https://docs.eximeebpms.org/manual/latest/webapps/cockpit/).
